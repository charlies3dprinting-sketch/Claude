# Household Real Estate — Facebook post graphics

Branded 1080x1080 graphics for Charlie Cook's Facebook deal posts (Just Listed / Under Contract / Just Sold / Just Leased).
They're generated by a weekly Claude task and published to the "Charlie Cook - Household Real Estate" page through Metricool,
which pulls each image from this public repo.

Files live in `graphics/`, named `<yyyy-mm-dd>-<address-slug>-<status>.png`.
